# Deepfake Detection Frontend

React + Vite frontend for deepfake detection system.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Update API URL in `.env` if needed

## Run

```bash
npm run dev
```

App will open at: http://localhost:5173

## Build

```bash
npm run build
```

Production files will be in `dist/` folder.
